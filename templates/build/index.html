Worked example

This site's booking API.

The Train room runs on a small JSON API in this same codebase. Open slots, session types and booking status are readable endpoints — which is how a widget, an app, or a client's own site hooks into it.

Open /train/api/slots/ 
# open slots for one session type
GET /train/api/slots/?session=1v1-session&limit=5
