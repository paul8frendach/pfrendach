# Paul Frendach — Claude pack

This is the locked house. Paste **`CLAUDE.md`** as the first message in a new Claude project. Put **`marks/`**, **`flash/`**, and **`fonts/`** in the new repo’s public folder. Do not redesign the logo.

## Order of files

| File | Job |
|---|---|
| **CLAUDE.md** | First prompt. Story, mark, tokens, three worlds, sting, architecture, do-nots. |
| **STING.md** | 10s intro / 10s outro timing and implementation. |
| **ASSETS.md** | What each graphic is for. |
| **DOCTRINE.md** | FRENDACH training voice, Seven Laws, Mother’s Law. |

## Locked in this pack

- House mark: Fraunces Regular, opsz 72, mirrored P back-to-back with F, stem overlap **−0.32em**.
- Primary wordmark: **ꟼFrendach** (mark + RENDACH). The F in the mark *is* the F in Frendach.
- Colors: Ink `#0B0D0C` · Bone `#F4F1EA` · Gold `#E8C36A`.
- Worlds: Create **Vision Oasis** (Glow) · Build (Steel) · Train **FRENDACH** (Gold).
- Sting: one P, PAUL centered, ꟼFrendach centered, F seats after the flip.

## Do not use from older folders

Anything named Attempt1, v1.5, v2 compact, Anton, Oswald, bowl tests, or `CLAUDE_FIRST_PROMPT.md` that still says Fraunces Bold / 0.27em overlap is **superseded**. This pack is the source of truth.
